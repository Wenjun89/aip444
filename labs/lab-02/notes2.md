# Introduction to Relational Databases and SQL

## Relational Databases
A relational database stores data in tables consisting of rows and columns. Each table represents a distinct entity, and relationships between tables are established using primary keys and foreign keys. Data integrity is maintained through constraints.

## Structured Query Language (SQL)
SQL is a standard language for storing, manipulating, and retrieving data in databases. Common operations include SELECT for querying data, INSERT for adding records, UPDATE for modifying existing records, and DELETE for removing records.

Example:
SELECT * FROM students WHERE program = 'Computer Programming and Analysis';
