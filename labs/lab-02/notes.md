# Introduction to Python Variables and Functions

## Variables
A variable is a container for storing data values. In Python, a variable is created the moment you first assign a value to it using the assignment operator (=). Python has no command for declaring a variable beforehand. Variable names are case-sensitive.

Example:
x = 5
y = "Hello, World!"

## Functions
A function is a block of code which only runs when it is called. You can pass data, known as parameters, into a function. A function can return data as a result. In Python, a function is defined using the def keyword.

Example:
def my_function():
    print("Hello from a function")
